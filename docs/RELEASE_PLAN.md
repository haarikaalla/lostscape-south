# Release plan

## GitHub

Code, configuration, tests, documentation, small traceable tables, public-safe figures, generalized inventory cells, and task manifests. Exclude raw downloads, credentials, precise coordinates, review material exposing sites, and large rasters.

## Archive/Zenodo

After final QA, archive the tagged public-safe release and record its DOI in `CITATION.cff`. Large reproducible derived products may be deposited separately only after coordinate and licensing review.

## Preconditions

All tests pass; `scripts/privacy_scan.py` passes; a clean rebuild is documented; repository size is checked; exact push file list is reviewed; no private/raw path is tracked; no performance number lacks a results file.
